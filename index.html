05 / Before you install

The important answers.

Is Underworld free?

Yes. There are no purchases, subscriptions, premium tiers, paid boosts, or pay-to-win benefits.

Does progress carry between servers?

No. Every server has an independent economy, balances, progression, and leaderboard.

Is this a gambling bot?

No. Underworld uses fictional currency with no real-world value. Nothing can be bought, sold, traded, transferred, or cashed out.

What does the bot store?

Discord IDs and the game state needed to keep progress working. Underworld does not store message content, usernames, email addresses, or payment details. Read the Privacy Policy for the full explanation.

What permission do I need to add it?

You need Manage Server in the Discord server where you want to install Underworld.
