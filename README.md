# Underworld website

Public landing page and legal pages for [joinunderworld.com](https://joinunderworld.com/).

- `/` explains the game and links to the Discord installation flow.
- `/invite/` redirects to Underworld's Discord authorization page.
- `/discord/` redirects to the official community server.
- `/privacy.html` and `/terms.html` contain the public policies.

The site is static and published through GitHub Pages. Plausible tracks aggregate visits plus the existing `Add Bot Click` and `Join Discord Server` conversion events.
