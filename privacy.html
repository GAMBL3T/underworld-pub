Your data,
without the fog.

Underworld stores the data needed to run a persistent, server-by-server game. We do not store the content of your messages.

The short version. We store Discord IDs and game state. We do not sell data, run ads, or collect message content. You can erase your game data with /forgetme. Website analytics and the limited operator records described below exist to keep the service running and improving.

What Underworld stores

DataWhy
Discord user and server IDsTo keep game progress separate for each person and server.
Balances, transaction history, rackets, Heat, streaks and cooldownsTo make the game work after restarts and prevent duplicate rewards.
Command outcomesTo safely replay a Discord command if Discord redelivers it.
Admin configuration history and optional audit-channel IDTo keep server settings accountable and send optional admin notices.
Server join and removal eventsTo measure installs and retention. These records are about servers, not individual players.

Discord messages and operator records

Underworld sends normal game responses to Discord. Those messages can show the current Discord display name of the person using a command. We do not store usernames, nicknames or display names in Underworld's database.

If a server enables Underworld's audit channel, configuration notices include the current display name of the administrator who made the change. Those notices are messages in that server's Discord channel, not database records. Deleting your data anonymizes your database audit record, but does not edit or delete messages already retained by Discord in a server's audit channel.

Underworld can also send a limited join or removal notice to a private operator channel in the official Underworld server. It may include the server name, server ID, member count when Discord provides it, event type, timestamp and whether the welcome message was delivered. It does not include the server owner ID. This channel is restricted to Underworld operators and is used to monitor installs and removals.

What we do not store in the game database

We do not store message content, usernames, nicknames, avatars, email addresses, IP addresses, payment details, or activity outside Underworld commands.

Delete your data

Run /forgetme in a server with Underworld. Choose either the current server or every server where Underworld holds your game data, then confirm the prompt yourself.

  • Deletion from the live game database is immediate and permanent.
  • Your balances, transaction history, rackets, Heat, streaks, cooldowns and stored command outcomes are removed together.
  • Server settings and server audit-channel messages remain.
  • Existing Discord messages and existing backup copies are not edited by /forgetme.

Backups are retained according to the active backup-rotation schedule, then expire when that backup is removed. If you no longer share a server with Underworld, or need a copy of your data, use the support route below.

Metrics and operational logs

Underworld's local operator metrics can show installation, retention and activity summaries by server. They do not include player IDs, player names, balances, command arguments or message content.

Limited runtime diagnostics may be retained by our hosting provider when an error occurs. They can include Discord user, server or channel IDs needed to diagnose the error. We do not intentionally log message content, display names, command arguments, balances or tokens.

Optional daily reminders

Reminders are off unless you enable them. We store your Discord user ID, the server IDs you enable reminders for, your preferences, and the scheduling and delivery state needed to send reminders without repeating them. Reminders for several servers may be combined into one Discord DM. Scheduling uses your game timestamps, not your online status or activity outside Underworld.

A separate reminder delivery log stores only your Discord user ID, the delivery-attempt time, and the outcome (sent, failed or blocked). It does not contain DM text, server or channel IDs, names, balances, or command arguments. Underworld operators use these records to troubleshoot reminder delivery. Records older than 30 days are removed during daily cleanup.

You can disable reminders for one server or all servers. Disabling reminders clears the selected preferences and pending reminders; existing delivery logs remain until they expire or you delete your data. Running /forgetme removes reminder preferences and pending reminders within your chosen deletion scope, plus all reminder delivery logs linked to your user ID, even if you choose just one server. Other servers where reminders remain enabled may generate new delivery logs.

Removing records from the live database does not delete DMs already delivered through Discord or edit existing backup copies. The backup-retention explanation above also applies to reminder records. These records are not sent to Plausible or posted in public Discord channels.

Website analytics

Our public website uses Plausible Analytics to measure aggregate page visits and clicks on the “Add Underworld” and “Join Discord Server” buttons. Plausible does not use cookies or persistent identifiers, does not store raw IP addresses, and does not track people across sites, devices or days. It receives the page URL, referral source, browser, operating system, device type and approximate location derived from the IP address before that address is discarded. We never send Discord IDs, game data or other account identifiers to Plausible. See Plausible's data policy.

Sharing and security

Underworld does not send game data to advertising or data-broker services. It communicates with Discord to run the bot and deliver its messages. The database and backups must be kept on encrypted storage, and off-box backups must be encrypted before transfer or storage.
