without the fog.

Underworld stores the minimum data needed to run a persistent, server-by-server game. We do not read or store your messages.

The short version. We store Discord IDs and the game state attached to them. We never sell data, run ads, use marketing tracking pixels, or collect message content. We use limited, cookie-free website analytics as described below. You can permanently erase your game data with /forgetme.

What we store

DataWhy
Discord user and server IDsTo keep game progress separate for each person and server.
Balances, transaction history, rackets, Heat, streaks and cooldownsTo make the game work after restarts and prevent duplicate rewards.
Command outcomesTo safely replay a Discord command if Discord redelivers it.
Admin configuration history and an optional audit-channel IDTo keep server settings accountable and send optional admin notices.
Server join and removal eventsTo measure aggregate installs and retention. This does not track individual players.

What we do not store

We do not store message content, usernames, nicknames, avatars, email addresses, IP addresses, payment details, or activity outside Underworld commands.

Delete your data

Run /forgetme in a server with Underworld. Choose either the current server or every server where Underworld holds your data, then confirm the prompt yourself.

  • Deletion is immediate and permanent.
  • Your balances, transaction history, rackets, Heat, streaks, cooldowns and stored command outcomes are removed together.
  • Server settings remain. If you changed a server setting as an admin, the setting history remains but your ID is replaced with an anonymous placeholder.

If you no longer share a server with Underworld, or need a copy of your data, use the support route below.

Retention and security

Game data stays until it is deleted. Removing Underworld from a server does not automatically erase its data today. The database and backups must be kept on encrypted storage, and off-box backups must be encrypted before transfer or storage.

Sharing and analytics

Underworld sends game data to no advertising or data-broker service. It communicates with Discord to run the bot. Local operator metrics contain only aggregate server counts; they never print player IDs or message content.

Our public website uses Plausible Analytics to measure aggregate page visits and clicks on the “Add Underworld” and the “Join Discord Server” buttons. Plausible does not use cookies or persistent identifiers, does not store raw IP addresses, and does not track people across sites, devices, or days. It receives the page URL, referral source, browser, operating system, device type, and approximate location derived from the IP address before that address is discarded. We never send Discord IDs, game data, or other account identifiers to Plausible. See Plausible’s data policy.
